# Study_Tracker_System
A Python-based Study Tracker application for managing subjects, tracking study hours, monitoring progress, and generating study reports


A Python-based Study Tracker application for managing subjects,
tracking study hours, monitoring progress, and generating study reports.

## Features
- Add multiple subjects
- Set target study hours
- Track real study hours
- Monitor study progress
- Completed / uncompleted status
- Study report
- Save and load data using JSON
- Clear all data

## Technologies
- Python
- OOP
- JSON
- Streamlit
